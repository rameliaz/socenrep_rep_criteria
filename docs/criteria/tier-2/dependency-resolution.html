Dependency resolution

Tier 2 · Executable - Silver core endorsement

Every add-on package or library the code needs is declared with its exact version, ideally in a machine-readable file (e.g. renv.lock in R) or an installation script (e.g. a setup.do in Stata), so that a user can install them on a new machine and the code finds them.

Rating

TipMet

The package contains a dependency management file or installation script (e.g. renv.lock or groundhog in R, a setup.do in Stata) that installs all required packages/libraries with their exact versions and runs successfully, or the README lists all packages/software used with their exact versions, and these can be successfully installed at the point of reproduction.

Supported by: Installer/lock file: #19 ‘installed/updated by a script’, #108 requirements.txt, #120 renv/conda/pip, #134 single installation script, #79 renv/checkpoint/groundhog. Listing with versions: #95 R3, #117, #40, #38 pin versions, #70, #48, #57, #7.

WarningPartially met

A dependency management file, installation script, or README list of dependencies is available, but it is incomplete (some packages or their versions are missing) or it cannot be successfully executed/installed at the point of reproduction (e.g. a package has been removed from its repository).

Supported by: #44 packages removed from CRAN, #103 deprecated packages, #61 version change breaks code, #143.

ImportantNot met

No dependency management file, installation script, or README information on dependencies is available.

Supported by: #10 ‘undocumented dependencies’, #73 ‘no information about how to install the project’, #77 manifest files ‘remain rare’.

NoteNot applicable

Never. If no add-on packages are used, met when the README says so.
