Computing environment

Tier 2 · Executable - Silver core endorsement

The system the code was run on is documented: operating system, version of the statistical software or programming language, and, where relevant, hardware and expected runtime. Ideally the environment is captured so it can be rebuilt (e.g. a container, virtual machine or cloud capsule) and the code runs the same way on another machine.

Rating

TipMet

The README (or a session-info/colophon file) documents the operating system and version, the statistical software or programming language and version, and, where relevant, hardware (CPU, RAM, cores, GPU/HPC) and expected runtime. Alternatively or additionally, the environment is captured so it can be rebuilt (e.g. a Dockerfile or container image with a pinned base, a virtual machine, or a cloud capsule such as Binder or Code Ocean) and it builds and runs on another machine.

WarningPartially met

Environment information is present but incomplete (e.g. software named without version, operating system missing, no runtime given for long computations); or a container/VM/capsule is provided but cannot be built or run at the point of reproduction.

ImportantNot met

No information on the computing environment is given and no captured environment is provided.

Based on: #19 three levels (documented with versions / built with a script / VM or container), #95 R3 OS + hardware specs, #14 hardware/system software/processors, #55 in code or README, #71 resources summarized in README, #128 ‘session info’, #40 pinned base image.

NoteNot applicable

Never.
