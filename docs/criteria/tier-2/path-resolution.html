Path resolution

Tier 2 · Executable - Silver core structural

The code finds its input and output files on any machine without edits: paths are relative to the package’s root folder, there are no hard-coded absolute paths or machine-specific working directories, and files sit in the folders the code expects.

Rating

TipMet

The code uses relative paths, the files sit in the folders the code expects, and the code successfully finds its input and output files on any machine without requiring any edits.

Supported by: #55, #39, #51, #117 relative paths, #93 ‘code contains relative file paths’, #26/#67 here(), #23 consistent working directory.

WarningPartially met

The code contains hardcoded local paths that cause execution errors, but these paths refer to existing folders/files, so they can be corrected manually or automatically; or the code uses relative paths but some files sit in a different folder than the code expects.

Supported by: Fixable hard-coded paths: #99 ‘minor and quickly resolvable changes such as adjustments to file paths’, #104 path redirection without penalty, #138 fixing paths not a failure, #134, #105, #131, #74, #15.

ImportantNot met

The code contains hardcoded paths that refer to folders/files that do not exist in the replication package. (If the files themselves are missing, this is scored under code/data deposit, not again here.)

Supported by: #25 missing files -> IOError, #112 files not in the execution directory, #125 references to an obsolete subfolder.

NoteNot applicable

Never.
