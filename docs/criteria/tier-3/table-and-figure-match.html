Table and figure match

Tier 3 · Reproducible - Gold core endorsement

The code regenerates every table and figure in the paper and appendix, and the regenerated items match the published ones in structure and appearance; for figures, this means the levels, shapes and positions of curves and data points.

Rating

TipMet

The code regenerates every table and figure in the paper and appendix, and each matches the published one in structure (rows, columns, panels) and content; for figures, the levels, shapes and positions of curves and data points are the same. Only cosmetic differences remain (fonts, colors, layout).

WarningPartially met

Some display items are regenerated and match, while others are missing (no code produces them, e.g. made by hand) or deviate; or items are regenerated with minor deviations that do not change what they show (e.g. slightly shifted points because no random seed was set, a difference of a few observations).

ImportantNot met

The code regenerates none of the tables and figures, or the regenerated items differ substantially from the published ones (different structure, trends or shapes).

Based on: #85 level, shapes and positions of curves/data points, #20/#93 all figures and tables incl. appendix, #99 match exactly, #104 match up to some decimals, #109 ‘Fully’ identical vs. ‘Partially’ slight deviation, #103 random seed for figures, #132 negligible discrepancies (two observations).

NoteNot applicable

Manuscript has no table or figure (C3)
