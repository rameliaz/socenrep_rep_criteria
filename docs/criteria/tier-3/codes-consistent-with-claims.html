Codes consistent with claims

Tier 3 · Reproducible - Gold core structural

The code does what the paper says it does: data preparation, samples, model specifications and estimators match the description in the paper, and results are computed by the code rather than copied in. This can be checked by reading the code against the paper, without running it (i.e., static code analysis).

Rating

TipMet

Reading the code against the paper (without running it) shows that data preparation (sample restrictions, exclusions, variable construction), model specifications and estimators (including controls and the level of standard-error clustering) match the paper’s description for all reported results, and every result is computed by the code rather than hard-coded or copied in.

WarningPartially met

The code matches the paper for the main results, but minor discrepancies are found that do not change the main findings (e.g. an undocumented outlier rule or control variable), or some results (e.g. in the appendix) cannot be traced to any code.

ImportantNot met

The code indisputably does something different from what the paper states for one or more main results (e.g. a different subsample, standard errors clustered at a different level, a different estimator), or results are hard-coded or copied in instead of computed. Differences in defensible analytical choices count as discrepancies only if the paper describes something else.

Based on: #17 ‘indisputably does not correctly carry out the test as described’, #98 clustering example, #109 check description vs. code, objective errors vs. analytical choices, #134 minor errors not changing major findings, #136 copied results rejected, #141 citations of descriptions vs. code.

NoteNot applicable

Never.
