Documentation

Tier 1 · Available - Bronze core endorsement

The replication package explains its own contents: a README lists every file, describes the data and states how to run the code to reproduce the results, and a codebook or data dictionary defines each variable with its values and labels. A third party should be able to understand and use the data without contacting the authors.

Rating

TipMet

A README file and a codebook are present. A README file contains at least: 1) a list and descriptions of all files in the replication package; 2) instructions on how to reproduce the results. A codebook should minimally contain: 1) variable labels and descriptions of what those mean; and 2) allowed values of each variable in the dataset.

Supported by: #42 README lists all files + purpose/format/provenance + how to replicate; codebook gives allowed values per variable. #48 codebook: all variables, definitions, values, value labels. #95 D3 codebook. #70 ‘no adequate data dictionary -> fail’. #55/#67/#137 README explains structure and contents. #19, #57, #69, #120, #97.

WarningPartially met

Either README or codebook is present, or both are present but their elements required in the “criterion_met” are incomplete.

Supported by: #14 (91% ‘data documented’, 57% ‘software documented’), #88 ‘insufficient documentation, missing information’, #133 ‘insufficient detail in README files’, #30 README present but context missing.

ImportantNot met

Neither README nor codebook are present.

Supported by: #17 ‘unlabeled and undocumented mess’, #70 fail without data dictionary, #58 data unusable without metadata.

NoteNot applicable

Never. When a replication package is a simulation study (C1), evaluate this criteria on the README alone.
