License

Tier 1 · Available - Bronze core endorsement

Every part of the package, code and data alike, carries an explicit license or terms of use, so others know whether and how they may use, modify and redistribute it. The authors have the right to share what they deposit.

Rating

TipMet

An open license (e.g. MIT, BSD, Apache 2.0, CC BY, CC0) allowing reuse, modification and redistribution is stated for all components the authors created (code and data alike), in the README, a LICENSE file, or the repository metadata. For third-party data the authors cannot relicense, the original terms of use are stated.

Supported by: Permissive/open license: #3 (attribution-only open licensing), #20 MIT, #99 MIT/BSD3, #108 MIT/Apache/CC BY, #54 CC BY default, #77 CC BY default, #83 open license required by AEA, #120 CC BY/CC0. Separate code + data licenses: #45. All elements: #35. Presence check: #93, #66, #19.

WarningPartially met

A license is stated, but it is not open (it restricts reuse, modification or redistribution of material the authors created), or a license is stated for only some components of the package (e.g. for the code but not the data).

Supported by: #45 one license missing (code or data) creates legal uncertainty. #34 data license prevents redistribution.

ImportantNot met

No license is stated in the package.

Supported by: #45 ‘no license … means that all copyright laws apply’, #48 unclear usage license as a barrier.

NoteNot applicable

Never.

#45 Toward reusable science with readable code and reproducibility · injunctive

“Our form features both data and code license fields as different types of licenses apply to these resources. The absence of one of the two licenses in a replication package with data and code may create legal uncertainty. Though the licenses should be open to allow reuse, no license within the published material means that all copyright laws apply and that the author retains all rights to data or code. To create a platform that facilitates reusable research, licenses for both types of resources needed to be incorporated.” (p. 4)
