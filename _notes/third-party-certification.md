## Packages containing datasets that cannot be shared

This criterion is recommended in general. For packages that do not contain all datasets needed because some cannot be shared, it becomes a core criterion: without a third-party certification, only the Tier 1 criteria are assessed, so the package can get at most Bronze. With a certification, the core criteria that need the data are rated from the certificate, so Silver and Gold become possible. See rules 3 and 4 in [How to read the rubric](../../about.qmd#a-snippet-of-the-badge-system).
:::
